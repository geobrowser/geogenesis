# Spinner

A 16×17 ring stroked with a ctaPrimary-to-pink gradient, rotating once a second. It is the one place a gradient appears in UI chrome.

**Props** — none. Prefer `Pending` dots or a pending label inside controls.

*Static rendition: the preview is plain markup carrying the class strings copied from the source, styled by `bundle.css` (a Tailwind compile of the app's own `styles.css`). Hover and focus are shown as separate samples where it matters.*

Source: `apps/web/design-system/spinner.tsx` (geogenesis master).
