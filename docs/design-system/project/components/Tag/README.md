# Tag

A tiny label: `inline-block rounded-sm px-1 pb-px text-[0.875rem] leading-none`, on `bg-grey-02` unless the caller passes a `bg-` class.

**When to use.** Type labels in search results ("Space", a type name, "+2") and the debates hub's "New" match tag. `tagStyles(className)` gives the classes for an element with its own ref.

**Props** — `ComponentPropsWithoutRef<'div'>`.

*Static rendition: the preview is plain markup carrying the class strings copied from the source, styled by `bundle.css` (a Tailwind compile of the app's own `styles.css`). Hover and focus are shown as separate samples where it matters.*
